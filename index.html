P2 Gold: Spiritbound

Contributions: I independently developed this project. This included designing and implementing the main "Spirit World" swap mechanic, which toggles the active state of platforms, hazards, and moving obstacles in real time. I also did the player controller with movement, jumping, designing and scripting multiple hazard types (instant-death spikes/water, rising water, crushing obstacles, and moving platforms). There is a checkpoint and respawn system that I implemented, It is platforming game that has escalating difficulty around the central mechanic, created a title screen, and added background music and visual effects.
